Agentic UX Concept

Smart Substitutions & Latency

A fast concept exploring how AI-driven substitution should feel in grocery e-commerce, designed around latency, trust, and deterministic fallback states.

Role Product Designer
Status 2026 Concept

The Problem

When an item goes out of stock in a grocery order, the default experience is manual: the customer either picks a replacement themselves or gets nothing. If an AI agent takes over that decision, it introduces a new problem: latency while it queries inventory and evaluates alternatives, and a trust gap when it presents a substitution the customer didn't ask for.

The question this concept answers: what does it look like to design for that exact moment?

The gap between "item unavailable" and "agent has a recommendation" without it feeling broken, slow, or untrustworthy?

Hypothetical Success Metrics

If shipped, this concept would be measured against three primary key performance indicators:

Metric 1

Acceptance Rate

Achieve >85% substitution acceptance rate by surfacing deterministic rationale chips.

Metric 2

Ticket Reduction

Measurable drop in customer support queries tied directly to unexplained auto-substitutions.

Metric 3

Resolution Time

Decrease average time-to-resolution on out of stock cart items during checkout.

Design Solutions

I designed three core screens that answer these constraints directly, establishing a highly secure, modern generative paradigm.

01: Thinking State

Handling Latency

The out of stock item shows a progressive loading component: sequential status text paired with a subtle progress indicator.

Why It Matters

LLM retrieval takes real time. Abstracting that wait into visible, conversational steps prevents abandonment and builds trust. These steps update via an aria-live region.

02: Recommendation

Building Trust

The agent presents two substitution options, each with a short rationale tag rather than just a name and price.

Why It Matters

AI recommendations need to feel deterministic, not magical. Surfacing the reasoning behind each option reduces cognitive load and cuts down on support tickets.

View Constraint & Fallback State

03: Graceful Degradation

If the LLM confidence score for a dietary match is below 95%, the UI must gracefully degrade to a manual search fallback to avoid compliance and health risks.

Deterministic Fallback States

Agentic UX cannot just be a chatbot. The actual fallback UI provides a clear "Low Substitution Confidence" message with two ways forward: search manually, or browse alternatives.

Reflection

The interesting design problem here wasn't the happy path. It was designing for uncertainty. Latency, confidence scores, and failure states are usually treated as engineering concerns that get bolted onto a UI after the fact. Treating them as first-class design decisions. Focusing on what the user sees while the system is unsure, and what happens when it is too unsure to act, is exactly where agentic products either earn trust or lose it.
